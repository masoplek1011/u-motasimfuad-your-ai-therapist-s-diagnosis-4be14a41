# Your AI Therapist's Diagnosis

One single-line diagnosis, delivered in a calm clinical voice: the patient's doomscrolling, reframed as an unpaid internship studying their own decline. The turn lands at the end, where the diagnosis stops sounding like a habit and starts sounding like a job description.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/ai-therapist-out node main.ts
```

This writes the diagnosis to `$MAKEFUN_OUTPUT_DIR/entry.txt` and prints nothing.
